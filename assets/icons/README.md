# 本地图标文件夹

这个文件夹用来存放"你自己指定"的网站图标,优先级最高——如果这里有对应的
图片文件,首页会优先显示这里的图,不会再去网上抓取。

## 什么时候用得上

自动抓取的图标(直接抓网站自己的 favicon.ico,抓不到再用第三方接口兜底)
大部分情况下够用,但总会有一些网站的图标本身就很丑、很模糊、或者是纯文字,
放在统一风格的卡片里显得不协调。这时候不需要改任何代码,只要把一张你觉得
好看的图片,存成规定的文件名放进这个文件夹,首页刷新后就会自动换成这张图。

## 命名规则

文件名 = 网站的域名,去掉开头的 `www.`,把所有 `.` 换成 `-`。

例如:

| 网址 | 应存成的文件名(不带后缀) |
|---|---|
| `https://mail.qq.com/` | `mail-qq-com` |
| `https://www.taobao.com/` | `taobao-com` (自动去掉了 www) |
| `https://code.visualstudio.com/` | `code-visualstudio-com` |

**同一个域名下不同路径的网址,共用同一个图标文件**(因为图标本来就是跟着
域名走的,不区分路径)。

### 关于 `icon-filenames-reference.txt`

这个文件**只是给你阅读用的参考表**,不是需要你去维护/编辑的映射文件——
你不需要在这个文件里做任何"网站对应图标名"的登记,代码也完全不会读取
这个文件。真正决定"这个网站该用哪个图标文件"的,是上面那条命名规则,
代码在渲染每张卡片的时候会根据网址自动算出对应的文件名去找。这个文件
存在的唯一作用,是省得你自己去算规则、去反查每个网站的域名——不确定
某个网站该存成什么文件名时,直接在这个文件里搜网站名称或网址就行。
(这个文件是一次性生成的参考资料,不是自动同步的,以后新加了很多新网站、
想要一份最新的对照表,直接跟我说一声,我可以帮你重新生成。)

## 图片要求

- **格式不限于 `.png`**,`.jpg` `.jpeg` `.webp` `.ico` 都可以直接放进来用,
  不需要先转换格式——代码会按 png → jpg → jpeg → webp → ico 的顺序自动
  挨个尝试,只要其中一种格式的文件存在就会用上。换句话说,
  `icon-filenames-reference.txt` 里写的文件名去掉后缀,后缀你自己按手头
  图片的实际格式来定就行,比如 `mail-qq-com.jpg` 或 `mail-qq-com.ico`
  都可以,不一定非要是 `.png`。
  (如果同一个域名你不小心存了好几种格式,只会用排在最前面的那个,
  也就是 png 优先、ico 排最后。)
- 尺寸不用太纠结,建议至少 64×64 像素,方形最好看(卡片上的图标容器是
  圆角正方形)。
- 文件名(不算后缀的部分)大小写、拼写要和上面对照表里完全一致,
  差一个字符就匹配不上。

## 图标的完整优先级顺序

1. **这个文件夹里的本地图片**(你手动放的,优先级最高;png/jpg/jpeg/webp/ico
   按这个顺序挨个试)
2. 网站自己域名下的 `/favicon.ico`(自动抓取,不依赖第三方)
3. 一个免费的第三方图标接口兜底(自动抓取)
4. 都没有 → 显示"网站名首字母"的纯色小图标,不会裂图

具体实现在 `assets/js/icon-fallback.js` 和 `assets/js/app.js` 的
`faviconChainHtml()` 里,一般不需要碰。
